# Metadata Configuration

The `metadata.toml` file at the repository root contains the artifact metadata
used for the ACSAC 2026 Artifact Evaluation submission.

It includes:
- The artifact repository URL.
- Claim definitions and verification mappings for the current artifact scope.
- Expected outputs corresponding to the canonical-result verifiers.
- Documented hardware and software requirements for artifact execution and
  optional reproduction.

The metadata has been generated and validated for the current artifact package.
